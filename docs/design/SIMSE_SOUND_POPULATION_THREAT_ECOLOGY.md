## 2. Generation-tag discipline (D012)

- Tags attach to **Black Hand-derived populations and technologies** only.
- **G0–G8 explain provenance, never excuse or supersede world rules.**
- Example: `G7 + human base + network infantry + Shade implant + containment role` — NOT simply "cool cyber soldier."
- Civilians, natural wildlife, and pre-lineage infrastructure heritage carry **no tag** (they predate or sit
  outside the lineage).
- A tag is the *reason-for-being* entry; it does not grant power. Rarity/horror budget (§30) and the
  human-first rule (§22) still apply to tagged content.

## 3. Primary ecology rule (progression)

Most encounters stay comprehensible as: **human · natural · military · technological · human-adjacent.**
The genuinely impossible remains uncommon and gated by provenance.

Progression felt by the player (canonical):

```
People are dangerous.
-> These soldiers are different.
-> These experiments should not exist.
-> Something happened that the experiments do not explain.
-> The island itself may be involved.
```

Saturation rule: no matter how far the player pushes, the ordinary layer (locals, weather, wildlife,
survival) must remain visibly present — it is the ground that makes later tiers read correctly (doctrine §23).

## 7. Shade information truth (network model, frozen)

Frozen sensing/network logic — **no omniscience** (doctrine §6/§8; BV-SKILL-008 truthful sensing):

```
individual observation -> local knowledge -> network propagation -> controller/squad knowledge -> tactical response
```

Information may originate from: direct vision · hearing · legitimate thermal/low-light systems · connected
cameras · drones · another Shade · commander systems · known-location memory.

- **A Shade cannot know the player's location merely because another AI system does.** Every knowledge carries a
  source, a channel, and a timestamp (BV-SKILL-008 knowledge-with-source).
- Network knowledge is REPORTED with cost, never telepathically synced exact coordinates.

Defined bounds (frozen):

| Boundary | Rule |
|----------|------|
| SQUAD BOUNDARY | beliefs propagate within squad linkage only; no cross-squad auto-knowledge without communication |
| SECTOR BOUNDARY | knowledge stops at the sector net edge (Frostvane relay = sector trunk, D012 §15); no omniscient map shared freely |
| INFORMATION LATENCY | propagation takes time (link ticks, hops); stale beliefs decay like perception (BV-SKILL-008 search states) |
| DEGRADED COMMS | interference, terrain, weather, distance degrade propagation (signals simulation-cheap, legible) |
| JAMMING | EW gear (role families) can block/limit propagation; jamming is telegraphed and counterable |
| CONTROLLER LOSS | losing a controller disrupts coordination, degrades sharing, triggers fallback (§8) |
| DESYNCHRONIZATION | individual desync -> isolated behavior, no network refresh, eventual broken/desync family state (§6) |
| FALLBACK BEHAVIOR | without network: prior orders, local autonomy, suspicion/search from own senses; never "knows anyway" |

No universal master controller exists (§8).

## 8. Shade commanders

Preserve D012 §17 commander externalization:

- Commanders do NOT use the same subordinate-control implant. Independent cognition retained because: command
  requires adaptation; leadership protects itself from subordinate risks; senior personnel understand implant
  damage; the organization values autonomy only at the top.
- Command hardware controls **bounded domains** (sector/squad allocations) — no universal master controller.
- Commander death has consequences short of instant mass shutdown:
  - disrupted coordination,
  - degraded information sharing,
  - fallback routines (Shades revert to local sense + prior orders),
  - confusion,
  - increased individual behavior (units act alone, more imaginative, less coherent).
- Comms/EW effects can produce the same degraded states (jamming, relay loss) — the player can *cause* these
  systemically, but no single kill equals everyone offline.---

- `human + Shade + recon + stealth kit + search behavior + synchronized + G7`
