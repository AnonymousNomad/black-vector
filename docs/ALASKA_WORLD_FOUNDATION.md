### 1.2 Why a composite, not a copy

- Doctrine §1/§5 require ONE continuous world. A single real site cannot supply every required terrain (doctrine §5):
  fjord coast, rainforest, alpine ridge, underground, barrier-island marine layer.
- Doctrine §16/§17 require fictionalization; copying a named real place or its real facilities is prohibited.
- So: study real regions for *terrain truth* (what grows, where, at what altitude; how weather and wildlife behave),
  then assemble an original region from those credible ingredients.

## §2 — Fictional Region: SIMSE SOUND [DESIGN]

- Setting: fictional Alaska-adjacent coastal region at ~59°N, maritime-subarctic (Dfc) climate [GEO-derived].
- Composite structure: PWS-style fjord/barrier-island geometry + Kodiak/Afognak-scale land density + Alaska
  Peninsula staging logic (seaplane/air/port infrastructure) + SE-coast vertical forest/alpine ladder.
- No real settlement, bay, sound, facility, or person shares a name with reality; all names below are fictional.
- Region is ONE continuous world (doctrine §5, §31); divided into sectors purely for activation/loading discipline
  (BV-SKILL-013) — the player never perceives level selection.
- Target land playable area: ~9–12 km² total across sectors [TECH target, pending SOP-004].
- Fabricated settlement identities implied: cannery-era coast, a biological station, a ridge relay, a mine town —
  enough human history for the restorable-facility cycle (doctrine §31) without reproducing real towns.

Key geographic facts (fictional but internally consistent):
- Winter solstice daylight ~5.3–5.6 h; summer solstice ~18.4 h; long civil-twilight extension [GEO-derived].
- Orographic rain: wet maritime faces vs dry inner faces → rain-shadow is authored geography [DESIGN].
- Glacial/drowned forest motifs exist but are rationed (overuse risk, §12).

## §5 — Architecture Reference Package [ARCH] + anti-videogame-architecture rule

Standard vocabulary drawn from real Alaska/Southern-Alaska rural+military construction logic. Every element carries
a *why-it-exists* reason (power, weather, access, cargo), not decoration.

- Barracks / bunkhouses: timber or quonset; heat, sleep, storage rationale.
- Hangars / maintenance: large single-span, equipment-scale doors.
- Communications towers: billboard-emitter + mast arrays (White Alice precedent), wind-exposed mount sites.
- Radar / EW shelters: armored/metal boxes, generator-backed.
- Fuel farms: remote tanks with spill-basin logic; hazardous-but-plausible siting.
- Generators / power plants: equipment rooms with heat load, fuel access, operator space.
- Docks / float ramps: weather-side vs lee-side logic for boats.
- Labs / offices: cramped, instrumented, paperwork-heavy interiors.
- Underground: engineered galleries (mine), buried corridors (Annex), pitted/bermed structures (Relay).
- Medical: functional field-med kit rooms, not fantasy hospitals.

Anti-videogame-architecture rule [DESIGN] (doctrine §11): every building answers "what was this FOR, here?"
A structure that exists only as a gameplay choke point or loot room is a design smell and is rejected.

## §6 — Weather System Foundation [DESIGN + TECH]

Goal (doctrine §6, §30): weather is a designed, legible survival/stealth/story mechanic — and a hazard — never a
pure ambience reel. Horror remains PERCEIVED-layer authored (BV-SKILL-018); weather is never a lone horror driver.

- One-truth shared state machine (single WORD source; all systems read the same state; observable via SOP-006):
  states: CLEAR / CLOUD / RAIN / SNOW / SLEET / STORM / FOG.
- Isochronal transitions (not instant swaps): 60–300 s ramps between states [TECH target].
- Season ladder: Dfc seasonal weighting changes state likelihood (snow/sleet winter-dominant, rain spring/fall,
  summer clearer, fog along coasts any season) [GEO-derived, stylized].
- Effect matrix (what each state does to: visibility, sound masking, movement, tracking, sensors, warmth):
  authored per state; legibility over fidelity.

## §7 — Wildlife Foundation [DESIGN + GEO]

Rule: credible regional wildlife; NO endless spawns; NO monster animals (doctrine §30; BV-D016 threat classes do not
apply to wildlife).

Two tiers:
1. AMBIENT / environmental — seabirds, Sitka-deer and Roosevelt-elk signal, marine mammals (seals/otters), shorebirds.
   Mood + world-reactivity; never combat fodder.
2. DECISION-BEARING / gameplay threats — brown bear, moose, black bear, wolves. Each uses real behavior ported to a
   bounded, legible rule set:
   - Brown bear: salmon-stream aggregation; ~100 m flight distance; bluff charges; play-dead/defense rule; winter
     denning silence (ADF&G Kodiak/Katmai-informed, stylized; [ASSUMED] on rule shape).
   - Moose: cow/calf + rut aggression; stomp/kick; bluff-charge; player answer = distance (ADF&G-informed).
   - Wolves: strongly avoidant; den-defense is vocal posturing not attack; no "wolf raid" content (ADF&G-informed).
   - Black bear: forested, camp/food-conditioned encounters near resting grounds.
- Territorial data, not scripts: species ranges exist as authored data; encounters emerge from that data + player
  signature (Pillar SIGNATURE), not from scripted monster appearances.
- Wildlife sensing uses the same bounded signature rules as human perception (doctrine §6).

## §8 — Survival System Boundary [DESIGN]

Doctrine §30: survival must create DECISIONS, not meter-busywork.

- KEEP (decision-producing): cold, wetness, storm/weather exposure, shelter capability, navigation.
- KEEP-LIGHT: fatigue and injury (threshold/conditional impact, not minute-to-minute meters).
- DROP as meters: hunger/hydration → replaced by meal/recovery beats (fresh water is abundant by setting; water
  pressure is place-based — "where can you get clean water / warm dry shelter here?"), not a water bar.
- Every kept system must be legible and consequential; anything that cannot be made simulation-cheap is redesigned
  or cut (doctrine §11).

## §9 — Stealth Environment Foundation [DESIGN]

Environment supports multi-channel signature reduction (doctrine §6, BV-SKILL-007) via authored surfaces:

- Vegetation cover: dense vs sparse foliage affects visual/silhouette channels; requires simulation-cheap modeling.
- Snow tracking: soft snow records movement; weather refills it (state-machine coupling to §6).
- Weather masking: rain/storm cut sound + visual ranges (legible, survival-flavored).
- Light cycles: daylight hours change detection; darkness is a channel, not a flag.
- Elevation/skyline: ridgelines silhouette; hollows/creek-beds conceal.
- No `hidden = true` anywhere; concealment is reduction across these channels.
