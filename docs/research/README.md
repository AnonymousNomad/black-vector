## How to use this ledger

1. A directive that touches a researched domain loads the matching research skill FIRST (registry routing), then
   reads the relevant ledger file below.
2. Source-record entries are the unit of record. Never write a historical fact into BLACK VECTOR canon without a
   source-record entry or an explicit `PURE BLACK VECTOR FICTION` marker.
3. When only ledger-level notes exist (no web re-verification this session), treat claims as
   `DISPUTED / INCONCLUSIVE` until re-verified against a named primary/near-primary source.

## Cross-cutting writing constraints (psychology / trauma / horror)

- Characters must never be violent because of a diagnosis (doctrine §23 ambiguity; D011-R §14). Violence comes from
  history, conditioning, circumstance, ideology, or choice — not "PTSD = dangerous." Use research (dissociation,
  hypervigilance, memory fragmentation, institutionalization) to write faithfully, never to excuse or equate.
- Horror derives from "believable systems pushed one step beyond the believable" (D011-R §15) — never from
  gore-spam or normalizing the supernatural; rarity is a design law (doctrine §23, BV-SKILL-018).
- Persistent pain is thematic, not cosmetic: Shade and The Hand each have their own sources (§13); the similarity is
  thematic only ("made powerful through systems that hurt them").
- No real-world chemical/dose/construction/torture/manual content is ever authored; the Compound is pure fiction.
