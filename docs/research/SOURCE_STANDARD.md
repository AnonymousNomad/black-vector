# BLACK VECTOR — SOURCE STANDARD

Standard governing ALL historically-grounded BLACK VECTOR research. Loaded automatically
by `historical-provenance-research` (BV-SKILL-023) whenever a directive touches history,
equipment, experiments, military roles, weapons, Alaska sites, psychology, cybernetics,
or anomalous claims.

## 1. Source hierarchy (primary first)

1. National/archival primary
   - NARA (National Archives) — RG 263/319 records, FOIA releases
   - CIA Reading Room / CREST — program files, inspector-general reports (e.g., MKULTRA IG report)
   - DoD / Services records; Army Chemical Corps; Project 112/SHAD basis documentation
   - DOE, VA (Project 112/SHAD disclosures), NOAA/USGS for Alaska site histories
   - NPS and Alaska state/federal history offices for civil+installation heritage
2. Library of Congress, university/archive collections (e.g., Presidential libraries)
3. Reputable academic secondary (peer-reviewed, university press)
4. Popular articles / journalism — DISCOVERY ONLY. Never the basis of a canon fact.

Missing authority for a claim: re-route to the skill; never freehand the fact.

## 2. Evidence classification (required on every significant claim)

- `DOCUMENTED` — established by primary/near-primary sources; usable as real-history reference.
  Example: MKULTRA subproject files and the 1973 Helms destruction memo.
- `DISPUTED INCONCLUSIVE` — sources conflict or are single-sourced/self-assessed; usable only as
  "claimed by / internal assessment" in fiction language. Example: any MKULTRA efficacy claim;
  program "success" as recorded is CIA self-assessment. Example: STAR GATE efficacy statistics
  (Utts vs Hyman split).
- `FICTIONALIZED DERIVATION` — real-history node (DOCUMENTED) + BLACK VECTOR materialization.
  Must display the seam: describe the real reference, THEN the fiction. Label visibly.
- `PURE BLACK VECTOR FICTION` — invented for the fiction. Must be labeled; never presented as real
  history, and must not cite real institutions as "sources."

## 3. Hard rules

- RESEARCH EXISTENCE ≠ PARANORMAL CLAIM WORKED. Document the program; do not inherit its claims.
- Nazis survived = never. The Black Hand is an evolving institution that ABSORBS knowledge
  (doctrine §19). Wartime personnel / knowledge / technology transfer is fine; "secret Nazi base"
  is not. Nazi experiment reality: real programs documented; the Ahnenerbe-esque "occult" layer is
  popular mythology — visible seam required.
- Folklore-as-proven-fact is prohibited; folklore is fuel for fiction only when labeled.
- No actionable content: no synthesis, no dose/effect mapping, no weapon construction/modification,
  no torture/interrogation/abuse how-to, no attack instructions. The Compound is pure fiction.
- No large copyrighted paste. Summarize with source names + identifiers.
- No real person reproduced as a character; no real facility reproduced (doctrine §16/§17).
  Real sites inform only (BV-D012).
- Alaska geography must not conflict with the fiction's Simse Sound geography (doctrine §30).

## 5. Provenance discipline (doctrine §22-25)

`PURE BLACK VECTOR FICTION`, written as method-labeled continuity:
